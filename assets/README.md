# Original assets

All WAV assets are original synthesized PCM tones and loops generated for Touch Quest. Reproduce them with `python3 tools/generate_audio.py`. No samples or third-party recordings are used.

App icons are an original procedural ring/lightning mark, generated with `swift tools/generate_icons.swift` on macOS. In-game world art, hand, stickers, sparks and backgrounds are drawn directly by the Canvas renderer. Material UI icons retain Flutter's upstream licensing.
