# Sharp branding source

`lib/ui/widgets/arcade_widgets.dart` contains the production `ArcadeLogo` and
`BeveledTitle` vector/text compositions. Flutter renders separate outline,
extrusion, glow and cyan/warm gradient layers at device resolution, using the
bundled Barlow Condensed ExtraBold Italic font. These components remain editable
and scale without a raster logo. No reference crop is used by the component.

Body font: Rajdhani SemiBold/Bold. Both font families are distributed under the
SIL Open Font License 1.1; license texts are in `assets/fonts/`.
